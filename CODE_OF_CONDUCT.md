# Code of conduct

NightZeros is a small studio that ships in the open. We expect the same standards here as we do in our products: useful, respectful, and specific.

## Expected

- Be direct and civil. Critique work, not people.
- Assume good intent, then ask clarifying questions.
- Keep security reports private until a fix is available.
- Credit others’ work.

## Not acceptable

- Harassment, discrimination, or personal attacks.
- Publishing others’ private information.
- Spam, or using this repo to advertise unrelated products.
- Publicly disclosing unpatched vulnerabilities.

## Scope

This applies to GitHub issues, pull requests, and discussions in NightZeros repositories.

## Enforcement

Report conduct issues the same way you would a serious product problem: privately, with enough context to act. Maintainers may warn, hide content, or block accounts that ignore this.

If you are reporting a software vulnerability, follow [SECURITY.md](SECURITY.md) instead.
