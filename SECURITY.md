# Security

NightZeros treats security as part of the product, not an afterthought.

## This website

This repository is the public marketing site ([nightszeros.com](https://nightszeros.com)). For product security (ChatAI, APIs, embeds, self-hosting), start here:

- [nightszeros.com/security](https://nightszeros.com/security)
- [docs.nightzeros.com/security](https://docs.nightzeros.com/security)

## Reporting a vulnerability

Please report privately. Do **not** open a public GitHub issue for an unpatched vulnerability.

Include:

1. Affected project, version, or URL
2. Steps to reproduce
3. Expected vs actual behavior
4. Impact (what an attacker could do, what data or functionality may be affected)
5. Supporting details (request/response examples, screenshots, a minimal proof of concept)

Give us a reasonable window to investigate and fix before public disclosure.

Follow the process on [docs.nightzeros.com/security](https://docs.nightzeros.com/security).
